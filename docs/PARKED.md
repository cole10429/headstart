# Parked

Left out of this version on purpose. Each is useful later, not on day one.

| Idea | Why it waits |
|---|---|
| Coordinating several sessions (who edits shared notes, merge order, sizing work per session) | Only pays off once someone runs several agents at once |
| A full model and effort routing table | Prices and model names change with every release. The kit keeps only the rules: helpers on Sonnet, reading on Haiku, `opusplan` suggested on smaller plans |
| Run the project's tests when Claude says it is finished, and send it back once if they fail | Works well, but needs a script copied to a fixed path plus each project's test command. The reviewer helper and the "done means you saw it work" habit cover most of it |
| Tips for one stack (Next.js and Vercel: browser-visible variables, local production check, preview setup) | Useful only once someone picks that stack, and goes stale with each release |
| Reply to and resolve every pull request review comment before merging | Needs pull requests and a review bot |
| A pre-push scan that refuses known private values | Needs a per-project list of what to refuse |
| A dated maintenance checklist with a start-of-session reminder | Nothing to maintain yet |
| Monthly quality check of past sessions | Needs months of history first |
| A custom output style | The profile already sets the reply shape. Claude Code's built-in Explanatory and Learning styles are worth trying first |
| Office and PDF file gate (load the matching skill before opening those files) | Depends on which document skills are installed |
| Turning off telemetry and automatic compaction | Personal choices with downsides (feature flags and updates can go missing). Left at Anthropic's defaults |
| A real macOS test of the installer | Needs a Mac |
